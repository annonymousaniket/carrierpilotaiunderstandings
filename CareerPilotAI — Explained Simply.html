1. The whole project in plain words

One sentence: CareerPilotAI is a website where you sign up, tell it your education, skills and the job you want, and an AI (Google Gemini) writes a career analysis and a 3-month learning roadmap for you, which is saved so you can view it later.

Think of a restaurant 🍽️

RestaurantYour project
Dining room (what customer sees)React frontend (login page, profile form, roadmap page)
Waiter carrying ordersAxios (sends requests to the backend)
KitchenExpress backend (Node.js server)
Security guard checking ticketsauthMiddleware.js (checks the JWT token)
Storage roomMongoDB (users, roadmaps, analyses)
Expert chef you call for hard dishesGemini AI

30-second interview version

"CareerPilotAI is a full-stack web app I'm building with React, Node/Express and MongoDB. A user registers and logs in, fills a career profile with skills and a target role, and the backend sends that profile to Google's Gemini API to generate a skill-gap analysis and a 3-month roadmap. The roadmap is stored in MongoDB per user. Login uses bcrypt password hashing and JWT tokens. It's still in progress: resume upload and resume analysis aren't finished yet."

The 3 things to burn in

① Every feature = page → function → Axios → route → (security guard) → controller → MongoDB/Gemini → back → state → screen.
② Be honest about what's unfinished. Interviewers respect that far more than a bluff.
③ The only files you must know cold are in tab 3.

Things in the repo that are NOT used (don't claim them)

Declared but unused: sequelize, mysql2 (the real DB is MongoDB), pdf-parse, mammoth (no PDF/DOCX parsing anywhere), @google/generative-ai + config/gemini.js (old Gemini SDK; the live code uses @google/genai).
Safe line: "I installed some libraries while exploring and haven't cleaned them up yet; the app uses MongoDB and Gemini."

Known bugs (say them yourself before they find them)

1. uploadMiddleware.js uses memoryStorage, so req.file.filename and req.file.path don't exist, but resumeController.js saves them as required fields. Upload would fail validation.
2. deleteResume uses Sequelize-style code (where, destroy()) on a Mongoose model. It would error.
3. Login says "User not found" vs "Invalid Password" separately, which leaks which emails exist.
4. cors() allows every website; api.js logs the token to the console; token lives in localStorage.
5. JSON.parse of Gemini output has no fallback if the AI returns bad JSON.
6. vite.config.js has base:'/CareerPilotAI/' and a GitHub Pages workflow, but the live site is on Vercel. ❓ I can't verify how that's reconciled.

Safe wording for the interview

"The current version has authentication, a career profile, AI skill-gap analysis, and AI roadmap generation stored in MongoDB. Resume upload and parsing is a planned extension: I've started the backend route but it isn't complete."
